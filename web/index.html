About CodeGuard

CodeGuard is a lightweight, local checkpoint that analyzes AI-generated code before it runs. It uses a combination of rule-based intent detection and a local ML model (TF-IDF + Logistic Regression) to provide high-accuracy safety verdicts.

Architecture

  • Backend: FastAPI (Python)
  • Analysis: Preprocess → LangID → Deobfuscate → Rules → ML → Fusion → Explain
  • Inference: CPU-only, scikit-learn

Latency

Targets p50 < 20ms, p95 < 100ms for typical snippets. Measured p50 ≈ 6 ms, p95 ≈ 18 ms.

Model

  • TF-IDF char n-gram (2–4) → One-vs-Rest Logistic Regression
  • Artifact ≈ 1.1 MB, loaded once at startup (models_loaded on /health)
  • Missing/corrupt model ⇒ automatic rules-only degrade

Limitations

  • Heuristic language ID and regex rules; not a full compiler/AST analysis.
  • Deobfuscation covers base64/hex/chr/alias/concat (not arbitrary crypto).
  • No external LLM calls; fully local and offline.
