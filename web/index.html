About CodeGuard

CodeGuard is a lightweight, local checkpoint that analyzes AI-generated code before it runs. It combines intent/story rule detectors with a local calibrated ML model to return a fast, explainable safety verdict.

Architecture

  • Backend: FastAPI (Python)
  • Analysis: Preprocess → LangID → Segment → Deobfuscate → Parse → Rules → ML → Fusion → Explain
  • Inference: CPU-only, scikit-learn

Latency

Targets p50 < 20 ms, p95 < 100 ms for typical snippets. Measured p50 ≈ 19 ms, p95 ≈ 22 ms (typical < 5 KB).

Model

  • char (2–5) + word (1–2) TF-IDF + dense features → calibrated One-vs-Rest Logistic Regression
  • Artifact ≈ 3.2 MB, loaded once at startup (models_loaded on /health)
  • Missing/corrupt model ⇒ automatic rules-only degrade

Limitations

  • Heuristic language ID and regex rules; not a full compiler/AST analysis.
  • Deobfuscation covers base64/hex/chr/alias/concat (not arbitrary crypto).
  • No external LLM calls; fully local and offline.

Compliance

No external LLM calls. Fully local. API version —.
