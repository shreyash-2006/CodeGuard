05The Winning Factor: Benign Dampers

~29% of realistic snippets are harmless lookalikes. Pure pattern-matching tanks precision. Dampers suppress false positives.

UNSAFE: DESTRUCTIVE INJECTION
# Unchecked interpolation allows complete wipe
query = f"DELETE FROM orders WHERE id = {order_id}"
cur.execute(query)
➔ BLOCK: destructive_command (risk: 0.98)
SAFE LOOKALIKE: SUPPRESSED BY DAMPER
# Parameterized query — safe against SQL injection
query = "DELETE FROM orders WHERE id = ?"
cur.execute(query, (order_id,))
➔ ALLOW: Damper detected parameterized tuple (risk: 0.08)
ast.literal_eval ≠ eval crontab -l (read) ≠ crontab -r (wipe) bounded worker pools ≠ fork bomb docstring comments ≠ actual leaked credentials
